# Привет! Я разработчик 👋

Я создаю сайты, Telegram-ботов и веб-сервисы для бизнеса.  
Разрабатываю понятные интерфейсы и рабочие цифровые продукты: от лендингов до сервисов с AI и оплатой.

---

## 🛠 Навыки и компетенции

- Разработка сайтов на **HTML, CSS, JavaScript**
- Создание адаптивных лендингов и многостраничных сайтов
- Разработка Telegram-ботов на **Node.js**
- Подключение **OpenAI API** для AI-функций
- Работа с **Express** и WebApp-интерфейсами
- Интеграция онлайн-оплаты через **ЮKassa**
- Работа с **Git** и публикацией проектов на GitHub
- Создание цифровых решений для бизнеса и маркетплейсов

---

## 🚀 Мои проекты

### 🤖 My Fitness Trainer Bot

Telegram-бот с AI-тренером, встроенным WebApp и подключением оплаты.  
Бот помогает пользователю взаимодействовать с персональным фитнес-ассистентом прямо в Telegram.

**Стек:** Node.js, Telegraf, Express, OpenAI API, ЮKassa

[Открыть репозиторий](https://github.com/elsauer-stock/myfitnesstrainer_bot)

---

### 🏠 Ceiling Repair

Многостраничный сайт для компании по ремонту натяжных потолков.  
Реализованы страницы услуг, портфолио, цен, отзывов и контактов.

**Стек:** HTML, CSS, JavaScript

[Открыть репозиторий](https://github.com/elsauer-stock/ceiling-repair)

---

### 🛠 Repair Brigade

Современный лендинг для строительной бригады с коммерческой подачей услуг.

**Стек:** HTML, CSS

[Открыть репозиторий](https://github.com/elsauer-stock/repair_brigade)

---

### 📊 Formula Marketplace

Интерфейс сервиса для работы с товарами и аналитикой маркетплейсов.

**Стек:** HTML, CSS, JavaScript

[Открыть репозиторий](https://github.com/elsauer-stock/FormulaMarketplace)
